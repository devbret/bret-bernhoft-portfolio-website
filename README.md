# Bret Bernhoft's Portfolio Website

![Screenshot from the top of the website.](https://hosting.photobucket.com/bbcfb0d4-be20-44a0-94dc-65bff8947cf2/7d3e4b88-fa95-482f-be66-149c12b2a2b8.png)

The professional portfolio of Bret Bernhoft, a software engineer who builds secure, scalable Quickbase applications, cloud automations and data-driven web experiences.

## Application Overview

A single-page portfolio walking visitors through who Bret is, the technologies he works with and what he has built. The about section traces his path from early WordPress development to enterprise systems, including his work leading the development of secure, scalable Quickbase applications and API integrations with a user-centric approach.

Next is the skills section which organizes his toolkit into six areas, including programming languages, artificial intelligence, frontend and DevOps. From there, a projects gallery hosts dozens of featured builds ranging from D3 data visualizations, OSINT tooling, Raspberry Pi experiments, local-LLM applications and homelab/Kubernetes documentation.

The page closes with LinkedIn endorsements from colleagues speaking to his technical depth and teamwork, followed by contact information for professional opportunities and technical mentoring.

## Basic Setup Instructions

Below are the required software programs and instructions for installing and using this application on a Linux machine.

### Programs Needed

- [Git](https://git-scm.com/downloads)

- [Node.js](https://nodejs.org/en)

### Steps

1. Install the above programs

2. Open a terminal

3. Clone this repository: `git clone git@github.com:devbret/bret-bernhoft-portfolio-website.git`

4. Navigate to the repo's directory: `cd bret-bernhoft-portfolio-website`

5. Install the frontend: `npm install`

6. Launch the frontend: `npm run dev`

7. Stop the development server: `CTRL + c`

## Other Considerations

This project repo is intended to demonstrate an ability to do the following:

- Build a single-page portfolio website using React, TypeScript, Vite, Tailwind CSS and other supporting libraries

- Integrate various Three.js effects including animated canvas, holographic design features and rotating contact globe

- Structure the skills and projects sections with typed data files so new portfolio cards can be easily showcased

- Communicate a coherent professional narrative by connecting Quickbase and web development experience to dozens of explorable project builds
